## 1. 渲染管线架构（Ch2）

**核心问题**：把 3D 场景变成 2D 屏幕像素，每帧需要多少次三角形处理？

**管线四阶段**（顺序，不可逆）：

1. **应用阶段**（CPU）：场景图遍历、剔除、LOD 选择、动画更新
2. **几何处理阶段**（GPU 顶点着色器）：顶点变换 → 光照 → 投影 → 裁剪 → 屏幕映射
3. **光栅化阶段**（GPU 固定功能/曲面细分/几何着色器）：三角形设置 → 三角形遍历（生成片元）
4. **像素处理阶段**（GPU 像素着色器 + 合并）：着色 → 深度测试 → 混合 → 输出到帧缓冲

**关键直觉**：
- 每个阶段都可能让数据量**减少**（剔除、裁剪）或**增加**（细分、置换）
- 性能优化的核心是**找瓶颈**——每个阶段的吞吐量和占用率都不同
- 顺序很重要：早做剔除 → 减少下游工作量

## 2. 顶点变换链（Ch4 §4.1.5）

**核心问题**：一个 3D 顶点如何最终出现在屏幕像素上？

**变换链**（列向量右乘，行主序矩阵）：
$$
\mathbf{v}_{clip} = P \cdot V \cdot M \cdot \mathbf{v}_{local}
$$

- $M$：模型矩阵（object → world）
- $V$：视图矩阵（world → camera/eye）
- $P$：投影矩阵（camera → clip space）
- 最后做透视除法 $\mathbf{v}_{clip} / w$ → NDC → 视口变换 → 屏幕坐标

**为什么这个顺序**？
- 模型空间：物体自己的坐标
- 世界空间：所有物体共享，便于光照和遮挡
- 相机空间：相机为原点，便于投影
- 裁剪空间：完成透视除法准备

**在 EasyMath 中**（`sandbox/sandbox.cpp` 演示）：
```cpp
auto model = MTXTranslation(2, 0, -5) * MTXRotationY(pi/4);
auto view  = MTXLookAt(eye, target, up);
auto proj  = MTXPerspective<float>(fov, aspect, near, far);
auto MVP   = proj * view * model;
auto clip  = MVP * vertex;  // 4D 齐次坐标
auto NDC   = clip / clip.w; // 透视除法
```

## 3. 四元数 vs 欧拉角 vs 旋转矩阵（Ch4 §4.3, §4.2.1）

**三种旋转表示的对比**：

| 表示 | 自由度 | 优点 | 缺点 |
|------|-------|------|------|
| 旋转矩阵 | 9（6 独立） | 直观、易组合 | 多冗余、需重正交化 |
| 欧拉角 | 3 | 易理解、紧凑 | **万向锁**、插值不连续 |
| 四元数 | 4（约束 $\|\mathbf{q}\|=1$） | 无奇点、slerp 平滑 | 4D、需归一化 |

**为什么用四元数做插值**？
- 欧拉角线性插值会产生不自然的中间姿态（如过山车翻转）
- 四元数球面插值（slerp）保证恒定角速度
- SLERP 公式见 `formulas.md §B.4`

**万向锁（Gimbal Lock）**：欧拉角中两个旋转轴重合时，丢失一个自由度。避免方法：用四元数或用旋转矩阵分解。

## 4. 法线变换（Ch4 §4.1.7）

**核心问题**：为什么不能直接用模型矩阵���换法线？

**原因**：非均匀缩放（如 $S = \text{diag}(2, 1, 1)$）会改变法线和切线的夹角——切线被拉长，法线如果不修正就指错方向。

**正确做法**：
$$
\mathbf{n}' = (M^{-1})^T \mathbf{n}
$$

即**逆转置**。对于纯旋转（无缩放），$M^{-T} = M$，所以和普通变换一样。

## 5. 着色模型演进（Ch5 → Ch9）

**演进路径**：
1. **Phong**（1975）：环境 + 漫反射 + 高光，简单但非物理
2. **Blinn-Phong**（1977）：用半向量替代反射向量，效率更高
3. **Cook-Torrance**（1981）：微表面理论 + 菲涅尔 + 几何遮蔽，开始物理正确
4. **GGX / Disney**（2010s）：NDF 改进（长尾）+ 艺术化参数

**关键直觉**：
- 真实感不是"加更多项"，而是**让每个参数有物理含义**（粗糙度、金属度、菲涅尔反射率）
- BRDF 是基础构件；复杂材质（皮肤、头发、布料）都是不同 BRDF 的组合

**Cook-Torrance 三件套**（见 `formulas.md §E.3`）：
- $D$：法线分布 → 控制"高光多锐"
- $F$：菲涅尔 → 控制"边缘更亮"
- $G$：几何遮蔽 → 控制"自遮挡"

## 6. 微表面理论（Ch9 §9.7）

**核心直觉**：宏观上"光滑"的表面，微观上是大量随机朝向的小镜面。
- **平均法线** = 宏观法线 $\mathbf{n}$
- **微观法线** = 各种倾斜 $\mathbf{h}$
- **NDF** $D(\mathbf{h})$：微观法线的分布密度
- **高光形状**就是 NDF 的"形状"

**为什么 GGX 流行**：比其他 NDF（Beckmann、Phong）有"更长的尾巴"——高光中心锐利、边缘柔和，更符合真实材质。

## 7. IBL / 环境贴图（Ch10 §10.4-10.6）

**核心问题**：环境光不是单一方向，而是来自所有方向（天空、其他物体反射）。

**预过滤环境贴图（Prefiltered Environment Map）**：
- 把环境光按"粗糙度"分层预卷积
- 查表时按材质粗糙度采样对应层
- 实现"模糊反射"的效果，无需实时卷积

**球谐（Spherical Harmonics）Irradiance**：
- 漫反射环境光只需低频 → 用 9 个 SH 系数即可重建
- 优势：9 个数字表达整个环境

**Split-Sum 近似**（Ch10 §10.5.2）：
- 镜面 IBL 拆成两部分：BRDF 积分 + 环境光积分
- 各预积分到 2D 查找表 → 实时只需两次纹理采样

## 8. 阴影算法对比（Ch7）

| 算法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **平面阴影** | 投影矩阵将阴影压到平面 | 简单 | 仅平面 |
| **阴影体** | 沿光向挤出轮廓 | 硬阴影精确 | 大量几何 |
| **阴影贴图** | 从光源深度图比较 | 通用、易 GPU | 锯齿、走样 |
| **PCF** | 阴影贴图区域采样 | 软阴影、便宜 | 不真实感（均匀软） |
| **PCSS** | 动态采样半径 | 真实感软阴影 | 较贵 |
| **不规则 Z-buffer** | 记录深度范围 | 软阴影、抗偏移 | 实现复杂 |

**关键直觉**：
- 阴影贴图的关键问题是**投影走样**——像素覆盖多个阴影贴图纹素
- PCF 用空间滤波换取软阴影，本质是"卷积"
- 真实感的"软阴影"应随距离变化（PCSS）

## 9. 纹理过滤（Ch6 §6.2）

**核心问题**：屏幕一个像素覆盖纹理多个纹素——怎么采样？

**Mipmap 链**：原图 + 缩小 2 倍 + 缩小 4 倍 + ...，按 LOD（细节层级）选择。

**LOD 计算**：屏幕空间像素对应纹理空间的"足迹"大小（双线性插值的导数）。

**各向异性过滤**：当足迹是椭圆（如观察斜面），单一 mipmap 层级不够——需要分别沿主轴缩放（RipMap）。

**为什么 trilinear 比 bilinear 好**：在两个 mipmap 层级间插值，避免 LOD 切换时突变。

## 10. 空间数据结构（Ch19 §19.1）

**选择决策**：

| 数据结构 | 适用场景 | 构造 | 查询 |
|---------|---------|------|------|
| **AABB 树** | 静态场景、刚体 | 快 | 较快 |
| **OBB 树** | 旋转物体 | 较慢 | 较慢但紧 |
| **k-DOP** | 紧致包围 | 较慢 | 较快 |
| **BSP 树** | 静态室内 | 较慢 | 快（但少用了） |
| **八叉树** | 均匀分布场景 | 快 | 中 |
| **BVH** | 动态场景、动画 | 快（SAH） | 快 |
| **场景图** | 层级组织、变换继承 | 手动 | 简单遍历 |

**BVH 构造的 SAH 启发式**：
- 每次切分时选最小化 $\text{cost}(A) + \text{cost}(B)$ 的方案
- 表面面积之比反映"被光线/视锥击中的概率"
- 比"中点切分"质量高 2-3 倍

## 11. 剔除策略（Ch19 §19.2-19.7）

**五层剔除**（按开销从小到大）：

1. **背面剔除**：用三角形法线点积视图方向，O(1) 每三角形
2. **视锥体剔除**：AABB 在视锥外就丢弃
3. **入口剔除**（Portal Culling）：开放世界分区域
4. **遮挡剔除**（Occlusion Culling）：用 HiZ 缓冲判断遮挡
5. **细节剔除**（Detail Culling）：小三角形跳过像素着色器

**关键直觉**：
- 每一层剔除只在前一层不通过时考虑
- 越早剔除 → 越省后续开销
- 但剔除本身有 CPU 开销 → 收益要大于成本

**HiZ 遮挡剔除**：
- 把深度图缩到 1×1、2×2、4×4 ... 形成层级
- 查询 AABB 在屏幕空间覆盖的最大深度 vs HiZ 同位置最小深度
- 若 AABB 最近深度 > HiZ 深度 → 被遮挡

## 12. LOD（Ch19 §19.9）

**核心直觉**：远处的物体不需要高细节。

**离散几何 LOD**：
- 预生成多套不同精度的模型
- 按距离/屏幕投影面积切换
- 缺点：切换时"跳变"

**混合 LOD / Geomorphing**：
- 切换时插值两个 LOD，避免跳变

**CLOD（连续 LOD）**：
- 运行时动态简化（边折叠）
- 没有"切换"概念，最平滑
- 贵，但适合大场景

**Alpha LOD**：
- 远处物体用 alpha billboard 替代
- 常用于树、草、粒子

**LOD 选择策略**：
- 基于范围（距离）：简单但不准
- 基于投影面积：准确但需要算屏幕投影
- 基于屏幕像素密度：精度自适应

## 13. 延迟着色 vs 前向着色（Ch20 §20.1）

**前向着色**（传统）：每个像素着色 N 次（N = 灯光数）

**延迟着色**：
1. 几何阶段：写入 G-buffer（位置、法线、材质 ID、深度）
2. 着色阶段：只对可见像素做光照累加

**优点**：光源数无开销、避免 overdraw 计算
**缺点**：G-buffer 带宽大、不透明才适合、MSAA 困难

**Tiled / Clustered Shading**（Ch20 §20.3-20.4）：
- 把屏幕分块（Tiled）或 3D 网格（Clustered）
- 每个 tile/cluster 找出影响它的光源
- 减少着色阶段的采样浪费

## 14. 碰撞检测流程（Ch25）

**三阶段漏斗**：

1. **宽阶段**：粗筛大量对象
   - 扫描剪枝（Sweep and Prune）：排序 AABB 在某轴的投影
   - 空间网格：哈希到格子里，只检查同格/邻格对象
   - 层次包围体：粗略 BVH

2. **中阶段**：精细筛可疑对
   - BVH vs BVH
   - OBB 树 vs OBB 树

3. **窄阶段**：精确测一对
   - GJK（Gilbert-Johnson-Keerthi）：两凸包最近距离
   - SAT（Separating Axis Theorem）：多边形-多边形
   - SAT 加速：Minkowski Sum

**GJK 核心**：把两凸包相减（Minkowski 差），找原点是否在差集内。等价于求最近点。

**SAT**：对两凸多边形的每条边作为分离轴做投影，若某轴上不重叠则不相交。

## 15. 实时光线追踪（Ch26）

**核心思想**：替代光栅化——从相机发射射线，对每个像素求与场景的最近交点。

**BVH 遍历**：
- 根节点入栈
- 弹栈，若 AABB 命中 → 推进子节点
- 叶子节点 → 测试三角形
- 用栈代替递归，避免 GPU 栈溢出

**Coherence（一致性）**：
- 临近射线倾向于命中临近物体 → 包排序（Mailbox）减少重测
- 构造时按表面积排序（SAH）→ 优先访问代价小的子树
- 三种 Coherence：光线间（inter-ray）、光线内（intra-ray）、帧间（temporal）

**降噪（Denoising）**：
- 每像素只 1 ray → 噪声大
- SVGF、NRD 等降噪滤波器
- 时域累积（reprojection）+ 空域滤波

## 16. GPU 架构要点（Ch23 §23.10）

**三种 GPU 架构对比**（case study）：

| | ARM Mali G71 (Bifrost) | NVIDIA Pascal | AMD GCN Vega |
|---|---|---|---|
| 着色器核心 | Scalar | SIMT (32 lanes) | SIMD (16-wide) |
| 调度 | 显式 warp | 硬件 warp scheduler | 显式 wavefront |
| 能耗 | 移动优先 | 桌面/笔记本 | 桌面/计算 |
| 主要特点 | 标量化省功耗 | 大 warp 隐藏延迟 | 标量化 + wave |

**关键概念**：
- **占用率（occupancy）**：活跃 warp 数 / 最大 warp 数
- **延迟隐藏**：通过切换 warp 隐藏内存延迟
- **ALU 占用率**：算术单元利用率（spills 寄存器会降）

## 17. PBR 关键参数语义（Ch9 §9.5.2）

**$F_0$（基础反射率）**：
- **电介质**（非金属）：$F_0 \approx 0.04$，与颜色无关
- **金属**：$F_0$ = 金属颜色（金/银/铜/铁/铝各有 RGB）

**粗糙度（roughness）$\alpha$**：
- $\alpha = 0$：镜面（高光小而锐）
- $\alpha = 1$：完全漫反射

**金属度（metalness）**：
- 0：电介质（$F_0 = 0.04$）
- 1：金属（$F_0$ = 颜色）

**Disney 重映射**：$\alpha = \text{roughness}^2$，让滑块"线性"对应视觉效果。

## 18. 实时抗锯齿（Ch5 §5.4）

**锯齿根因**：信号（连续图像）欠采样（屏幕像素）→ 高频信号折叠成低频"阶梯"。

**MSAA（多重采样）**：每个像素多个采样点，共享着色器输出，只对覆盖测试独立。**只解决几何锯齿，不解决着色锯齿**。

**屏幕空间 AA**：
- **FXAA**：后处理边缘检测，廉价
- **TAA**：时域累积 + 抖动 → 接近电影级
- **SMAA**：形态学亚像素形态识别

**TAA 核心**：
- 当前帧用抖动相机投影矩阵采样
- 把上一帧的像素重投影到当前帧，做 blend
- 抗锯齿 + 动态模糊 + 抗闪烁一体化

## 19. 体积渲染核心（Ch14）

**参与介质**（雾、烟、云、水）：光线在介质中不断被吸收/散射。

**辐射传输方程（RTE）**：
$$
L(s, \omega) = T(s) L_0 + \int_0^s T(x) \sigma_s(x) L_{in}(x, \omega) dx
$$

其中 $T(s) = e^{-\int_0^s \sigma_t(x) dx}$ 是透光率（Beer-Lambert 定律）。

**相位函数**（描述散射方向）：
- **瑞利散射**：小颗粒（空气），前向/后向对称
- **米氏散射**：大颗粒（水滴），强前向
- **Henyey-Greenstein**：参数化散射各向异性

**单次散射近似**：忽略多次散射（合理但低层云不准）。

## 20. 渲染数学核心恒等式

- **点积**：$\mathbf{a} \cdot \mathbf{b} = \|\mathbf{a}\| \|\mathbf{b}\| \cos\theta$
- **叉积**：$\mathbf{a} \times \mathbf{b}$ 方向由右手定则
- **反对称矩阵**：$\mathbf{a} \times \mathbf{b} = K(\mathbf{a}) \mathbf{b}$，其中
$$
K(\mathbf{a}) = \begin{pmatrix} 0 & -a_z & a_y \\ a_z & 0 & -a_x \\ -a_y & a_x & 0 \end{pmatrix}
$$
- **泰勒展开**：$\sin\theta \approx \theta - \theta^3/6$，$\cos\theta \approx 1 - \theta^2/2$（小角度）
- **向量反射**：$\mathbf{r} = \mathbf{d} - 2(\mathbf{d} \cdot \mathbf{n})\mathbf{n}$
- **向量折射**：$\mathbf{t} = \eta \mathbf{d} + (\eta c - \sqrt{1 - \eta^2(1-c^2)})\mathbf{n}$，$c = -\mathbf{d}\cdot\mathbf{n}$
