# Ch3 The Graphics Processing Unit 图形处理单元

**核心问题**：GPU 如何实现渲染管线？什么是数据并行？

---

## 3.1 数据并行结构

**核心思想**：GPU 用大量小处理器（ALU）并行执行相同指令。

**对比 CPU**：
- CPU：少量复杂核心，大缓存，分支预测
- GPU：大量简单核心（如 1024+），无大缓存

**GPU 关键概念**：
- **SIMD**（Single Instruction Multiple Data）：所有 ALU 同步执行同一条指令
- **SIMT**（Single Instruction Multiple Threads）：NVIDIA 的术语，每个线程有独立状态
- **Wavefront**（AMD）：相当于 32 或 64 个线程
- **Warp**（NVIDIA）：32 个线程

**为什么适合图形**：
- 顶点处理：每个顶点独立
- 像素处理：每个像素独立
- 计算着色器：GPGPU

---

## 3.2 GPU 管线概述

**现代统一着色器架构**：
- 不再有"顶点处理器"和"像素处理器"分离
- 所有 ALU 都可以跑顶点/像素/计算着色器
- 调度器动态分配工作

**典型 GPU 流水线**：
1. 命令处理器接收 draw call
2. 几何引擎处理图元
3. 顶点着色器（可编程）
4. 曲面细分
5. 几何着色器
6. 光栅化
7. 像素着色器（可编程）
8. 合并（ROP）

---

## 3.3 可编程着色器阶段

**三种主要着色器**：
- **顶点着色器**（Vertex Shader）：每顶点一次
- **像素着色器**（Pixel/Fragment Shader）：每片元一次
- **计算着色器**（Compute Shader）：通用 GPGPU

**输入/输出**：
- 顶点 → 通过 vertex attribute 传
- 像素 → 通过 varying 传（顶点输出插值）
- 计算 → 通过 buffer 共享

---

## 3.4 可编程着色及其 API 的演变

**历史**：
- 固定功能管线（DX7 之前）
- 顶点/像素着色器（DX8-9）
- 统一架构（DX10+）
- 计算着色器（DX11+）
- 光线追踪着色器（DX12 DXR）

**关键 API**：
- DirectX（HLSL）
- OpenGL（GLSL）
- Vulkan（SPIR-V）
- Metal（MSL）

---

## 3.5 顶点着色器

**功能**：
- 顶点变换（MVP）
- 顶点属性计算（法线、切线、副切线）
- 输出到 varying 供像素着色器使用
- 早期还能做纹理采样（少用）

**限制**：
- 不能直接丢弃图元
- 不能访问邻居顶点
- 不能原子操作

---

## 3.6 曲面细分阶段

**三个新着色器**（HLSL）：
- **Hull Shader**：控制"何时细分"（patch 级别）
- **Tessellator**：固定功能，实际细分
- **Domain Shader**：控制"细分后位置"（每个新顶点）

**用途**：
- LOD 动态调整
- 模拟连续曲面（地形、生物）
- 节省带宽（只传控制点）

---

## 3.7 几何着色器

**输入**：整个图元（点/线/三角形）
**输出**：可变数量的图元

**用途**：
- 细分（如分裂为多面）
- 简化（合并多个为少个）
- 生成（如粒子从顶点发射）
- 立方体贴图（cube shadow map）

**问题**：性能因驱动而异，逐渐被计算着色器替代。

### 3.7.1 流式输出

把顶点着色器或几何着色器的输出**流回缓冲区**（不进入光栅化）。
- 用于多 Pass 渲染
- 用于模拟（粒子系统、CUDA 风格）

---

## 3.8 像素着色器

**输入**：插值后的顶点属性
**输出**：颜色 + 深度 + 模板（可选）

**能力**：
- 纹理采样
- 复杂数学（指数、对数）
- 原子操作（modern GPU）
- 早期限制：无分支（现代已不严格）

**早期 GPU 限制**：
- 指令数有限
- 寄存器数有限
- 纹理数有限

---

## 3.9 合并阶段（Output Merger）

**不可编程**，但可配置：
- **深度测试**（always, never, less, equal, ...）
- **模板测试**
- **混合**（add, multiply, alpha, premultiplied, ...）
- **逻辑操作**

---

## 3.10 计算着色器

**通用 GPGPU**：
- 不连接渲染管线
- 读写任意 buffer
- 线程组（Thread Group，通常 64-1024 线程）
- 共享内存（group-shared）
- 同步（group sync）

**应用**：
- 粒子系统
- 图像处理（后处理）
- 物理模拟
- 蒙皮计算
- 光线追踪构建 BVH

---

## 与 EasyMath 项目关联

**低**——本章是硬件层，与 CPU 端数学库关联不大。

**但是**：
- EasyMath 的 `Vector`/`Matrix` 性能应考虑 GPU SIMD 友好性
- 后续添加 PBR 时，BRDF 评估应考虑在 GPU 上的指令数和分支

## 关键术语索引

| 术语 | 释义 |
|------|------|
| SIMD | 单指令多数据 |
| SIMT | 单指令多线程（NVIDIA 术语） |
| Warp | 32 线程组（NVIDIA） |
| Wavefront | 32-64 线程组（AMD） |
| 统一着色器架构 | 所有 ALU 等价 |
| Hull/Domain Shader | 曲面细分 |
| 流式输出 | 顶点回流到 buffer |
| 计算着色器 | GPGPU |

## 关键概念

**延迟隐藏**：通过 warp 切换隐藏内存延迟（与占用率成反比）。

**占用率**（Occupancy）：活跃 warp 数 / 最大 warp 数。占用率低 → 隐藏延迟能力差。

**ALU 利用率**：算术单元实际使用率（spills 寄存器会降低）。
