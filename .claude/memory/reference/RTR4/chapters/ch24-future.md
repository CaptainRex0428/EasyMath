# Ch24 The Future 未来

**核心问题**：实时渲染未来会怎么发展？

---

## 24.1 其他事项

**趋势预测**：
- **光线追踪普及**：RTX、PS5、XSX 推动
- **混合渲染**：光栅化 + 选择性光线追踪
- **AI 加速**：DLSS、FSR、XeSS 上采样
- **神经辐射场**（NeRF）
- **全息显示**
- **VR/AR 普及**

**算法方向**：
- 神经 BRDF
- 神经去噪
- 神经辐射缓存
- 物理模拟 + 渲染统一

**硬件方向**：
- 专用 RT Core
- 更大显存
- 移动 GPU 接近桌面

## 24.2 你

**对读者的建议**：
- 读 SIGGRAPH 论文
- 玩商业引擎的源代码
- 实践：实现小项目
- 关注会议：SIGGRAPH、GDC、Eurographics
- 持续学习：领域发展快

**学习路径**：
1. 掌握基础（数学、API、CPU/GPU）
2. 深入一个领域（渲染、模拟、动画）
3. 了解相关领域（计算机视觉、深度学习）
4. 实践 + 论文
