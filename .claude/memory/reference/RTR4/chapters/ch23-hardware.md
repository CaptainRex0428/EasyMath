# Ch23 Graphics Hardware 图形硬件

**核心问题**：现代 GPU 是如何工作的？

---

## 23.1 光栅化

### 23.1.1 插值
**重心坐标插值**：
$$
\mathbf{p} = \alpha \mathbf{v}_0 + \beta \mathbf{v}_1 + \gamma \mathbf{v}_2
$$
其中 $\alpha + \beta + \gamma = 1$。

**透视校正插值**：除以 w 修正透视失真。

### 23.1.2 保守光栅化
**核心**：包含整个像素（即使只部分覆盖）。

**用途**：碰撞检测、AI 可见性。

---

## 23.2 大规模计算和调度

**SIMD / SIMT**：
- 多个线程同步执行
- Warp 切换隐藏延迟
- 调度器负责

**Warp 调度**：
- NVIDIA：32 线程/warp
- 调度器选择就绪 warp 执行
- 等待内存时切换

---

## 23.3 延迟和占用率

**延迟源**：
- ALU 延迟（1-2 周期）
- 纹理采样（10+ 周期）
- 内存访问（数百周期）

**占用率**：活跃 warp 数 / 最大 warp 数。

- 高占用率 → 更好隐藏延迟
- 低占用率 → GPU 资源浪费

**平衡**：
- 寄存器太多 → 占用率低
- 太少 → 寄存器 spill 到内存

---

## 23.4 内存架构和总线

**现代 GPU 内存层次**：
- **寄存器**（per thread，超快）
- **L1 缓存**（per SM）
- **L2 缓存**（全 GPU 共享）
- **VRAM**（DDR/GDDR，数百 GB/s）

**总线宽度**：256-1024 bit，影响带宽。

**带宽公式**：
$$
\text{BW} = \text{BusWidth} \times \text{ClockRate} \times 2 \text{ (DDR)}
$$

---

## 23.5 缓存和压缩

- **纹理压缩**：BC、ASTC（减少 VRAM 带宽）
- **帧缓冲压缩**：AFBC（移动）、DCC（NVIDIA）
- **Delta 颜色压缩**（DCC）：相邻像素差
- **Z 压缩**：相邻深度值压缩

---

## 23.6 颜色缓冲

### 23.6.1 视频显示控制器
**核心**：把帧缓冲转换为显示信号。

**历史**：
- VGA（模拟）
- DVI（数字）
- HDMI
- DisplayPort

### 23.6.2 单、双、三重缓冲
- **单缓冲**：易撕裂
- **双缓冲**：交换避免撕裂
- **三重缓冲**：额外一帧让 CPU 提前工作

---

## 23.7 深度剔除、测试和缓冲

- **Early-Z**：深度失败早返回（节省像素着色）
- **Hierarchical Z**：粗粒度早期拒绝
- **Re-Z**：合并阶段再做深度测试
- **Z-prepass**：先渲深度，剔除远像素

---

## 23.8 纹理化

- 各向异性过滤（专用硬件）
- mipmap 自动选择
- 浮点纹理（R16F、R32F、RG16F、R11G11B10F）
- 块压缩纹理（BC 系列）

---

## 23.9 架构

**统一着色器架构**（现代）：
- 所有 ALU 等价
- 调度器动态分配
- 最大化利用率

**传统固定功能**（老 GPU）：
- 顶点/像素分离
- 不灵活

---

## 23.10 案例分析

### 23.10.1 ARM Mali G71 Bifrost
- 移动 GPU
- 标量化（每线程独立）
- 节能优先

### 23.10.2 NVIDIA Pascal
- 桌面/笔记本
- SIMT（32-lane warp）
- 大 warp 隐藏延迟

### 23.10.3 AMD GCN Vega
- 桌面/计算
- 16-wide SIMD wavefront
- 标量化 + wave

---

## 23.11 光线追踪架构

**专用 RT Core**：
- **BVH 遍历硬件**
- **三角形求交硬件**
- 节省 ALU 资源

**代表**：
- NVIDIA RTX
- AMD RDNA 2+
