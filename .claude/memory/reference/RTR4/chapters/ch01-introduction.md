**章节定位**：全书开篇，定义术语、解释范畴、给出章节地图。

---

## 1.1 实时渲染定义

**三个必要条件**（缺一不可）：
1. **交互性**：观察者的输入能立刻影响下一帧图像
2. **三维场景**：渲染对象是 3D 数据（不是 2D 图像处理）
3. **图形加速硬件**：依赖 GPU（自 1996 年 3Dfx Voodoo 起普及）

**帧率参考**：
- 1 FPS：用户能感觉到逐帧
- 6 FPS：开始有交互感
- 30 FPS：游戏最低
- 60 FPS：流畅
- 90+ FPS：VR 必需（延迟 < 15ms）

**注意**：FPS（显示速率）和 Hz（刷新率）是两个概念。例如电影 24 FPS 但快门 72 Hz。

## 1.2 符号和定义（Ch1.2）

**全书符号约定**（与 EasyMath 高度一致）：

| 类型 | 符号 | 示例 |
|------|------|------|
| 角度 | 小写希腊字母 | $\theta, \phi, \alpha$ |
| 标量 | 小写斜体 | $t, s$ |
| 向量/点 | 粗体小写 | $\mathbf{v} = (v_x, v_y, v_z)$ |
| 矩阵 | 粗体大写 | $\mathbf{M}$ |
| 集合 | 黑板粗体 | $\mathbb{R}$ |
| 区间 | $\mathbb{R}^3$ | 3D 实数空间 |

**重要术语**（后续章节会用到）：
- $L$ = radiance（辐射度，单位面积单位立体角的光功率）
- $E$ = irradiance（辐照度，单位面积的光功率）
- $\sigma_s$ = 散射系数
- $\mathbf{n}$ = 法线
- $\mathbf{l}$ = 光照方向
- $\mathbf{v}$ = 视线方向
- $\mathbf{h}$ = 半向量 $(\mathbf{l}+\mathbf{v})/||\mathbf{l}+\mathbf{v}||$

**渲染方程**（Ch11 会展开）：
$$
L_o(\mathbf{p}, \mathbf{v}) = \int_{\Omega} f_r(\mathbf{l}, \mathbf{v}) L_i(\mathbf{l}) (\mathbf{n} \cdot \mathbf{l}) d\mathbf{l}
$$

> **与 EasyMath 关联**：符号约定可作为项目 API 文档的格式参考。
