## 18.2 定位性能瓶颈

**每阶段的瓶颈不同**：

| 阶段 | 常见瓶颈 |
|------|---------|
| 应用 (CPU) | 物理、AI、场景遍历 |
| 顶点处理 | 顶点变换、复杂的顶点着��器 |
| 光栅化 | 大量过绘制 |
| 像素处理 | 复杂片段着色器、纹理采样 |
| 合并 | 带宽、深度测试失败 |

### 18.2.1 应用阶段测试
**降低分辨率**（按比例）：看 FPS 是否提升
- 不变 → 应用是瓶颈
- 提升 → GPU 是瓶颈

### 18.2.2 几何处理阶段测试
- 简化顶点着色器
- 减少 draw call

### 18.2.3 光栅化阶段测试
- 减少过绘制
- 优化视锥体/遮挡剔除

### 18.2.4 像素处理阶段测试
- 简化片段着色器
- 减少纹理采样
- 早 Z 优化

### 18.2.5 合并阶段测试
- 减少混合操作
- 减少帧缓冲写入

## 18.4 优化

### 18.4.1 应用阶段
- **内存问题**：
  - 避免每帧分配（用对象池）
  - 减少缓存未命中（数据局部性）
  - SIMD 友好布局

### 18.4.2 API 调用

- **状态改变**：
  - 减少切换着色器
  - 减少切换纹理
  - 减少切换顶点缓冲
  - 状态排序（按材质）

- **合并和实例化**：
  - **批处理**（Batching）：相同材质的几何合并
  - **实例化**（Instancing）：相同几何的多实例
  - **合批阈值**

### 18.4.3 几何处理阶段
- 简化顶点着色器
- **顶点缓存**友好布局
- 减少属性数量
- 早 Z 优化

### 18.4.4 光栅化阶段
- 减少 overdraw
- 优化三角形顺序
- 背面剔除

### 18.4.5 像素处理阶段
- 简化片段着色器
- **Early-Z**：深度失败早返回
- **HiZ**：层级深度拒绝
- 减少纹理采样
- 着色器分支优化

### 18.4.6 帧缓冲技术
- **多缓冲**：前后缓冲 + 深度
- **带宽优化**：
  - 减少帧缓冲读写
  - 压缩渲染目标（BC、ASTC）
  - Tile-based 渲染（移动 GPU）

### 18.4.7 合并阶段
- 早 Z 拒绝
- 减少混合
- 减少深度/模板测试

## 与 EasyMath 关联

**中**——EasyMath 的性能直接影响应用阶段。

**优化方向**：
- SIMD 友好（std::array 已经连续）
- 模板实例化时减少代码膨胀
- constexpr 函数（编译期计算）
- 避免不必要的拷贝

## 关键术语

| 术语 | 释义 |
|------|------|
| 瓶颈 | 最慢的阶段 |
| 批处理 | 合并 draw call |
| 实例化 | 一次 draw 多次实例 |
| Early-Z | 深度失败早返回 |
| 占用率 | 活跃 warp 比例 |
| 带宽 | GPU 内存带宽 |
| 帧时间 | 单帧渲染时间 |
| Render Graph | 声明式渲染图 |
