# Agents 配置

此目录用于配置专门的 AI 代理，用于特定任务。

## 代理规划

### 1. quaternion-expert
**专长**: 四元数实现与优化
- 精通四元数数学
- 了解旋转表示转换
- 熟悉数值稳定性问题

### 2. simd-optimizer
**专长**: SIMD 指令优化
- SSE/AVX 指令集
- 向量化算法
- 性能分析

### 3. color-scientist
**专长**: 颜色科学与色彩空间
- 颜色空间转换
- 感知均匀性
- 伽马校正

### 4. ue-integrator
**专长**: Unreal Engine 集成
- UE 插件开发
- 模块系统
- 性能优化

## 代理配置格式

- 专业领域
- 系统提示
- 工具访问权限
